PDF sang văn bản

Lấy toàn bộ chữ trong PDF để sao chép hoặc lưu file .txt.

File của bạn được xử lý ngay trên máy này, không bao giờ tải lên máy chủ.

Nhận: PDF

Cách dùng

  1. Chọn hoặc kéo thả một hay nhiều file PDF.
  2. Chọn có ghi số trang hay không, có nối các dòng bị ngắt giữa câu hay không.
  3. Bấm “Lấy văn bản”, xem ngay, sao chép toàn bộ hoặc tải file .txt.

Câu hỏi thường gặp

File có bị tải lên mạng không?

Không. Mọi bước xử lý chạy bằng JavaScript ngay trong trình duyệt của bạn; file không rời khỏi máy.

Vì sao không lấy được chữ từ file của tôi?

File PDF scan (chụp hoặc quét từ giấy) chỉ chứa ảnh, không có lớp chữ. Hãy dùng công cụ Ảnh sang chữ (OCR).

Mở file .txt bằng Notepad bị lỗi font tiếng Việt?

File được lưu dạng UTF-8 có đánh dấu BOM nên Notepad, Word đều nhận đúng tiếng Việt.

Có giữ được bảng biểu, định dạng không?

Không. Công cụ chỉ lấy chữ thuần; bảng biểu được chuyển thành các dòng chữ.

Công cụ liên quan

  • Ảnh sang chữ (OCR)

    Nhận dạng chữ trong ảnh chụp, ảnh scan, hỗ trợ tiếng Việt có dấu.

  • PDF sang ảnh

    Chuyển từng trang PDF thành ảnh JPG hoặc PNG chất lượng cao.

  • Ghép PDF

    Nối nhiều file PDF thành một file, kéo thả để sắp thứ tự, xoay từng file nếu cần.

  • Tách PDF

    Tách PDF theo khoảng trang, mỗi trang một file hoặc trích các trang bạn chọn.
