Công cụ Văn phòng & dữ liệu

Xem Excel/CSV, chuyển đổi, gộp, tách file Excel, trộn thư, chữ ký email, soạn văn bản hành chính. 9 công cụ miễn phí, chạy ngay trên trình duyệt.

  • Xem file Excel/CSV

    Mở xem file .xlsx, .xls, .ods, .csv không cần cài Excel; chuyển sheet, tìm không cần dấu, lọc, sắp xếp.

  • Excel ↔ CSV

    Chuyển Excel sang CSV UTF-8 không lỗi font tiếng Việt (mỗi sheet một file) và CSV sang Excel, giữ số 0 đầu.

  • Gộp nhiều file Excel

    Gộp nhiều file hoặc nhiều sheet Excel/CSV thành một bảng, tự ghép đúng cột cùng tên, thêm cột nguồn.

  • Tách Excel theo cột

    Tách một bảng thành nhiều sheet hoặc nhiều file Excel/CSV theo giá trị của một cột (chi nhánh, phòng ban…).

  • JSON ↔ Excel

    Chuyển mảng JSON thành bảng Excel (làm phẳng đối tượng lồng nhau) và Excel/CSV thành JSON.

  • Trộn thư

    Từ danh sách Excel/CSV và mẫu Word (.docx) hoặc văn bản, tạo hàng loạt giấy mời, thư: DOCX từng người, DOCX gộp để in, hoặc PDF.

  • Tạo chữ ký email

    Tạo chữ ký email HTML chuyên nghiệp cho Gmail, Outlook: ảnh, logo, mạng xã hội, sao chép dán ngay.

  • Tạo hoá đơn, báo giá

    Lập báo giá, phiếu bán hàng (hoá đơn bán lẻ): chiết khấu, thuế GTGT, số tiền bằng chữ, mã QR chuyển khoản, xuất PDF.

  • Soạn văn bản hành chính (NĐ 30)

    Nhập cơ quan, số hiệu, trích yếu, nội dung để tạo file Word đúng thể thức Nghị định 30/2020: quốc hiệu, tiêu ngữ, font, lề, nơi nhận.

Về nhóm Văn phòng & dữ liệu

Xem file Excel, CSV không cần cài Office, chuyển Excel sang CSV và JSON, gộp nhiều file Excel thành một, tách bảng theo cột, trộn thư từ danh sách Excel và mẫu Word, tạo chữ ký email, hoá đơn, báo giá và soạn văn bản hành chính đúng Nghị định 30.

Câu hỏi thường gặp

Mở file CSV bị lỗi font tiếng Việt thì sao?

Các công cụ tự nhận bảng mã (UTF-8, Windows-1258…) và dấu phân cách khi đọc CSV; file CSV xuất ra có BOM UTF-8 để Excel mở đúng tiếng Việt.

Công thức và định dạng trong Excel có được giữ không?

Công cụ đọc giá trị đã tính của từng ô; khi gộp, tách hay chuyển đổi, file mới chứa giá trị chứ không giữ công thức, màu ô hay ô gộp.

Đọc được những loại file nào?

Excel .xlsx, .xls, .ods và CSV; Trộn thư dùng thêm mẫu Word .docx.

    Cách tạo chữ ký email có họ tên, chức vụ, logo, mạng xã hội rồi cài vào Gmail và Outlook; chữ ký nên có gì, bỏ gì và vì sao ảnh hay bị mất.

  • Chuyển Excel sang CSV không lỗi font tiếng Việt

    Vì sao file CSV mở bằng Excel bị lỗi chữ tiếng Việt, mất số 0 đầu số điện thoại, và cách chuyển Excel sang CSV UTF-8, CSV sang Excel cho đúng.

  • Cách tách file Excel thành nhiều file, nhiều sheet theo cột

    Cách tách một bảng Excel thành nhiều sheet hoặc nhiều file theo giá trị của một cột như chi nhánh, phòng ban, lớp học, không cần công thức hay macro.

  • Cách gộp nhiều file Excel thành một và tách lại theo cột

    Hướng dẫn gộp nhiều file hoặc nhiều sheet Excel, CSV thành một bảng, tự ghép đúng cột cùng tên, và tách một bảng thành nhiều file theo chi nhánh.

  • Cách trộn thư từ danh sách Excel và mẫu Word

    Hướng dẫn tạo hàng loạt giấy mời, thư, giấy chứng nhận từ danh sách Excel và mẫu Word ngay trên trình duyệt, cách viết trường, đặt tên file và in một lần.

  • Thể thức văn bản hành chính theo Nghị định 30/2020

    Tóm tắt quy định trình bày văn bản hành chính theo Nghị định 30/2020/NĐ-CP: khổ giấy, lề, phông chữ, cỡ chữ từng thành phần, số ký hiệu và quyền hạn ký.
