Công cụ Văn phòng & dữ liệu

Xem Excel/CSV, chuyển đổi, gộp, tách file Excel, trộn thư, chữ ký email. 8 công cụ miễn phí, chạy ngay trên trình duyệt.

  • Xem file Excel/CSV

    Mở xem file .xlsx, .xls, .ods, .csv không cần cài Excel; chuyển sheet, tìm không cần dấu, lọc, sắp xếp.

  • Excel ↔ CSV

    Chuyển Excel sang CSV UTF-8 không lỗi font tiếng Việt (mỗi sheet một file) và CSV sang Excel, giữ số 0 đầu.

  • Gộp nhiều file Excel

    Gộp nhiều file hoặc nhiều sheet Excel/CSV thành một bảng, tự ghép đúng cột cùng tên, thêm cột nguồn.

  • Tách Excel theo cột

    Tách một bảng thành nhiều sheet hoặc nhiều file Excel/CSV theo giá trị của một cột (chi nhánh, phòng ban…).

  • JSON ↔ Excel

    Chuyển mảng JSON thành bảng Excel (làm phẳng đối tượng lồng nhau) và Excel/CSV thành JSON.

  • Trộn thư

    Từ danh sách Excel/CSV và mẫu Word (.docx) hoặc văn bản, tạo hàng loạt giấy mời, thư: DOCX từng người, DOCX gộp để in, hoặc PDF.

  • Tạo chữ ký email

    Tạo chữ ký email HTML chuyên nghiệp cho Gmail, Outlook: ảnh, logo, mạng xã hội, sao chép dán ngay.

  • Tạo hoá đơn, báo giá

    Lập báo giá, phiếu bán hàng (hoá đơn bán lẻ): chiết khấu, thuế GTGT, số tiền bằng chữ, mã QR chuyển khoản, xuất PDF.
