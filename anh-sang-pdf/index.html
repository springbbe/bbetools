Ảnh sang PDF

Ghép ảnh JPG, PNG, ảnh chụp màn hình thành một file PDF.

File của bạn được xử lý ngay trên máy này, không bao giờ tải lên máy chủ.

Nhận: JPG, PNG, WebP, GIF, BMP, AVIF, HEIC, HEIF

Cách dùng

  1. Chọn, kéo thả hoặc dán (Ctrl/⌘ + V) các ảnh: JPG, PNG, HEIC, ảnh chụp màn hình…
  2. Sắp thứ tự trang bằng kéo thả hoặc nút ↑↓, xoay ảnh bị ngược; chọn khổ giấy, hướng trang, lề và chất lượng.
  3. Bấm “Chuyển sang PDF” rồi tải file về.

Câu hỏi thường gặp

File có bị tải lên mạng không?

Không. Mọi bước xử lý chạy bằng JavaScript ngay trong trình duyệt của bạn; file không rời khỏi máy.

Ảnh chụp từ iPhone (HEIC) có dùng được không?

Được. Công cụ tự đọc ảnh HEIC và xoay đúng chiều theo thông tin trong ảnh.

Làm sao để file PDF nhẹ hơn?

Chọn chất lượng “Nhẹ”. Nếu vẫn lớn, dùng tiếp công cụ Nén PDF.

Mỗi ảnh thành một file PDF riêng được không?

Được, tắt “Gộp tất cả ảnh vào một PDF”; các file sẽ tải về từng file hoặc gộp trong một file .zip.

Công cụ liên quan

  • PDF sang ảnh

    Chuyển từng trang PDF thành ảnh JPG hoặc PNG chất lượng cao.

  • Ghép PDF

    Nối nhiều file PDF thành một file, kéo thả để sắp thứ tự, xoay từng file nếu cần.

  • Nén ảnh

    Giảm dung lượng ảnh JPG, PNG, WebP hàng loạt; có chế độ nén xuống dưới số KB bạn cần.

  • Tách PDF

    Tách PDF theo khoảng trang, mỗi trang một file hoặc trích các trang bạn chọn.
