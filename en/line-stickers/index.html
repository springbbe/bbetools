LINE Sticker Downloader

Paste a LINE Store link to download a whole LINE sticker or emoji set: original PNG, animated APNG with sound, or converted to GIF. No login needed.

BbeTools has no server: your browser downloads straight from LINE's server (stickershop.line-scdn.net). No login, and no LINE account details are sent.

How to use

  1. Open the sticker or emoji set on store.line.me and copy the page address (or in the LINE app: sticker set page → Share → Copy link).
  2. Paste it into the Link box and click “Get sticker set”; the whole set downloads, including animations and sounds.
  3. Choose PNG + GIF or the original format, then click “Download all (.zip)” or click a sticker to download just that one.

Frequently asked questions

Do I need to log in to LINE or buy the set?

No login is needed. The page only downloads the image files that the LINE Store shows publicly, for you to save for personal use. To send the stickers in LINE you still need to get or buy the set in LINE.

What file format are animated LINE stickers?

The originals are animated PNG (APNG), which open in browsers, Telegram, Discord and graphics apps. Choose “PNG + GIF” to convert them to GIF that works everywhere. Stickers with sound also get an .m4a file with the same number.

Why do GIF edges look jagged?

GIF pixels are either fully transparent or not, so soft sticker edges get rounded off. Pick a White (or Black) background that matches where you'll paste them for smooth edges, or keep the animated PNG (original format).

Can I download LINE emoji too?

Yes. Paste an emoji set link like store.line.me/emojishop/product/… ; animated emoji are converted to GIF just like stickers.

Can I use downloaded stickers commercially?

No. Stickers are copyrighted by their creators. Download them for personal use only, or with the creator's permission.
