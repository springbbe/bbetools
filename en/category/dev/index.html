Developer tools

JSON, Base64, JWT, UUID, hashes, regex, timestamps, cron, colors, SQL. 19 free tools that run right in your browser.

  • JSON Formatter & Validator

    Beautify, minify, sort keys and validate JSON, pointing to the exact line/column of errors.

  • JSON ↔ CSV/YAML Converter

    Convert back and forth between JSON, CSV and YAML.

  • Base64 Encode/Decode

    Encode and decode Base64 for UTF-8 text and files.

  • URL Encode/Decode

    Encode/decode URLs (percent-encoding) and break down query parameters.

  • HTML Entity Encoder

    Convert special characters to HTML entities and back.

  • JWT Decoder

    View a JWT's header, payload and expiry; verify HMAC and public-key signatures.

  • UUID Generator

    Generate UUID v4 and v7 in bulk.

  • Hash Generator (MD5/SHA)

    Calculate MD5, SHA-1, SHA-256 and SHA-512 hashes of text.

  • Regex Tester

    Test regular expressions with highlighted matches and capture groups.

  • Unix Timestamp Converter

    Convert Unix timestamps ↔ dates in your local time zone and UTC.

  • Cron Expression Explainer

    Explain cron expressions in plain English and list the next run times.

  • Color Converter

    Convert HEX, RGB, HSL and OKLCH; check text/background contrast.

  • CSS Gradient & Box-Shadow Generator

    Visually adjust gradients, box-shadows and border-radius, then copy the CSS.

  • SQL Formatter

    Beautify SQL statements (MySQL, PostgreSQL, SQL Server…).

  • JS/CSS/HTML Minifier

    Minify JavaScript, CSS and HTML code to reduce size.

  • Number Base Converter

    Convert numbers between binary, octal, decimal, hexadecimal and any base.

  • Chmod Calculator

    Convert Linux file permissions between numeric (755) and rwx forms.

  • User-Agent Parser

    See the browser, operating system and device from a User-Agent string.

  • HTTP Status Codes

    What 1xx–5xx codes (404, 500, 301…) mean, explained in plain English.
