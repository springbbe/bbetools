About & privacy

BbeTools is a collection of free utility tools that run entirely in your browser. It started in Vietnamese and is now available in English too.

Your files never leave your device

BbeTools has no processing server. When you merge PDFs, compress images or make ID photos, every calculation runs in JavaScript and WebAssembly right in your browser tab. Files, text, camera images and microphone audio aren't sent anywhere. You can even go offline once the page and libraries have loaded, and the tools keep working.

What does the site load from the Internet?

  • The website itself, from GitHub Pages.
  • Fonts and open-source libraries (pdf-lib, pdf.js, JSZip, image encoders, HEIC decoder, QR reader…) from the jsDelivr CDN, pinned to exact versions. Heavy libraries only load when you open a tool that needs them. The CDN only sees the library requests, never your files.
  • The background-removal AI models (for ID photos) are hosted on this website itself.
  • The Telegram Sticker Downloader is the one exception: your browser talks directly to Telegram's servers (api.telegram.org) with your own bot token to fetch the sticker set. BbeTools has no server in between and never receives the token.

Visit statistics, no ads

BbeTools uses Google Analytics to count page views (which pages are used most, where visitors come from, phone or computer), so we know which tools to improve. Google Analytics only receives the page address; file names, file contents, text and numbers you enter into tools are never sent. You can block it with an ad blocker or the Google Analytics opt-out add-on; every tool keeps working.

No ads, no advertising cookies. “Recently used”, “Favorites” and settings are only stored in your own browser storage (localStorage); clearing site data removes them.

Open source

All the source code is at github.com/springbbe/bbetools. You can review it, send feedback or report bugs under Issues.

Limitations

Since everything runs on your device, speed depends on your device: very large files (hundreds of MB) may be slow or run out of memory on older phones. Calculation results are for reference only; data with legal implications shows its update date on each page.
